# 2026-09-25 — Add web tools

## Scope
Port of `D:\workspace\testing\web-search.js` into seven tools, on branch
`feat/web-tools` (base `main`). Google (headless browser) is the default engine;
no API key required.

## What changed
- `src/types/web.d.ts`: search, fetch, batch, brief, research, verification types.
- `src/utils/web-core.ts`: HTTP with timeout, entity decoding, HTML to text,
  title extraction, URL canonicalization, public-URL guard, disk cache.
- `src/utils/web-engines.ts`: DuckDuckGo, headless-browser Google, Google Custom
  Search API, Google suggest, browser discovery, render, goto resolution.
- `src/utils/web-fetch.ts`: page fetch, PDF text extraction, sitemap crawl.
- `src/utils/web-search.ts`: dispatch, dedupe annotation, ranking, quality
  labels, batch, multi-source corroboration, summary, freshness/source
  verification, research storage.
- `src/tools/web.ts`: `web.search`, `web.fetch`, `web.suggest`, `web.summary`,
  `web.batch`, `web.verify`, `web.research`.
- Registered in `defaultTools`; `tests/web.test.ts` covers the pure helpers.

## Tool contracts
- `web.search`: `query`, `engine` (default `google`), `limit`, `tab`, `fresh`,
  `site`, `multiSource`, `noCache`.
- `web.fetch`: `url`, `mode` (`document` | `sitemap`), `maxLength`; supports PDF.
- `web.suggest`: `query`.
- `web.summary`: `query`, `top`, `excerptLength`, engine options.
- `web.batch`: `queries`, engine options.
- `web.verify`: `query`, `checks` (`freshness`, `sources`).
- `web.research`: `action` (`save` | `list`).
- `google-api` remains available but is never required.
