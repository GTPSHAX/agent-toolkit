# 2026-09-25 — Add MCP stdio server

## Scope

## What changed
- `src/mcp.ts`: JSON-RPC 2.0 handler and stdio loop; `createMcpServer`,
  `runMcpServer`, protocol constants and message types.
- `src/cli.ts`: new `mcp` subcommand; help text updated.
- `src/index.ts`: export the MCP entry points and types.
- `tests/mcp.test.ts`: 9 tests.

## Protocol contract
- Transport: newline-delimited JSON-RPC 2.0 on stdin/stdout; nothing else is
  written to stdout.
- Methods: `initialize`, `notifications/initialized`,
  `notifications/cancelled`, `ping`, `tools/list`, `tools/call`.
- Version negotiation: echoes a supported client version, otherwise returns
  `2025-06-18`. Supported: `2025-06-18`, `2025-03-26`, `2024-11-05`.
- `tools/list` returns `name`, `title`, `description`, `inputSchema`,
  `outputSchema`.
- `tools/call` returns the tool `ToolOutput` as the MCP result; unknown tools
  return JSON-RPC error `-32602`.
- Errors: `-32700` parse, `-32601` unknown method, `-32602` invalid params.

## Client configuration
- opencode (`opencode.json`/`.jsonc`): key `mcp`, entry `"type": "local"`,
  `command` as a single array. Example:
  `{"mcp": {"agent-toolkit": {"type": "local", "command": ["node", "dist/cli.js", "mcp"], "enabled": true}}}`
- Claude Desktop/Cursor: `mcpServers` with `command` + `args`.
