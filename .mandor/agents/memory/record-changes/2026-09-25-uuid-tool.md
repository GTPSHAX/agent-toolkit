## Tool contract
- Input: `{ action: "generate" | "validate", count?, upper?, value? }`.
- `generate`: returns `uuids` (default 1, range 1..100), `nil`, `max`.
- `validate`: returns `valid`, and when valid `normalized`, `version`,
  `variant`.
- Invalid action, out-of-range count, or missing `value` returns
  `isError: true`.

## Sources
- RFC 9562 (`rfc-editor.org/info/rfc9562`): 16-octet UUID, hex-and-dash form,
  UUIDv4 random, Nil UUID (Section 5.9), Max UUID (Section 5.10), variants and
  versions tables. Obsoletes RFC 4122.
