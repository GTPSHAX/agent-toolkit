## Tool contract
- Input: `{ text: string, algorithm?: HashAlgorithm }`; default `sha256`.
- Output `structuredContent`: `{ algorithm, digest }`.
- Algorithms: `md5`, `sha1`, `sha256`, `sha512` (hex via `node:crypto`);
  `protonhash` (32-bit, 8 lowercase hex digits); `protonhash64` (BigInt,
  decimal string).

## ProtonHash facts (sourced)
- Origin: Proton SDK by Seth Robinson (RTsoft), per `iFika/ProtonHash` README.
- C reference (`realyukii/proxy`, `src/utils/crypto.c`):
  `int hash = 0x55555555; while(*data) hash = (hash >> 27) + (hash << 5) + *data++;`
- TS reference with wide variant (`blancos13/growtopia-bot-ts`,
  `src/utils/crypto.ts`): `protonHash` uses `>>> 0`; `protonHash64` uses
  `BigInt`.
- Implementation uses UTF-8 bytes for `protonhash`; UTF-16 code units for
  `protonhash64`.
- Reference values: `protonHash('') = 0x55555555`, `protonHash('a') = 0xaaaaab0b`,
  `protonHash('hello') = 0xb15ee899`, `protonHash('items.dat') = 0xcbf3b3f8`.
